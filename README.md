## 📖 About This Repository

This repository is a **one-stop resource** for mastering System Design. It covers:

- 🔵 **High-Level Design** — Scalability, Distributed Systems, Caching, Load Balancing, Databases, and 25+ core topics
- 🟢 **Low-Level Design** — SOLID Principles, Design Patterns (Creational, Structural, Behavioral), Multithreading, and real-world examples

Each topic is written as a **self-contained markdown file** with clear explanations, diagrams, and code examples — perfect for quick revision or deep study.
